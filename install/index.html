One-time setup · about a minute

Install the MIghTy extension

This is what lets MIghTy read LinkedIn pages you're already viewing and show real match scores. It never clicks Connect or Message for you — you always click Send.

1

Download MIghTy

Click the button below to download the extension as a .zip file.

⬇ Download MIghTy extension
2

Unzip it

Find the downloaded file (usually in your Downloads folder) and double-click it to unzip — you'll get a folder called mighty-extension.

3

Open chrome://extensions

In Chrome, type chrome://extensions into the address bar and press Enter.

4

Turn on Developer mode

Flip the "Developer mode" toggle in the top-right corner of that page.

5

Click "Load unpacked"

A new button appears on the left — click it, then select the mighty-extension folder you unzipped in step 2.

6

Sign in

The MIghTy icon appears in your toolbar — click it (pin it for easy access), then sign in with your @mit.edu email, same account as the web app.

You're in control

MIghTy never clicks Connect, never sends a message, and never automates LinkedIn. It only reads pages you're already viewing and logs sends you make yourself.
